# P3. 잔병치레 케어맘 — "박은정" (★주력 페르소나★)

> 페인 강도: ★★★★★ (최상) · 역할: **과제1 제출용 핵심 페르소나**

## 프로필

| 항목 | 내용 |
|---|---|
| 나이 | 44세 |
| 가족 | 초등 자녀 2명(잔병치레 잦음), 맞벌이 |
| 현재 상태 | **이미 종합비타민 + 유산균 + 비타민D를 먹이는 중**, 환절기 맞아 면역 영양제 하나 더 추가 고민 |
| 구매 채널 | 쿠팡·네이버, 맘카페 정보 참고 |

## 한 줄 정의
> "지금 먹이는 것들이랑 겹치는지, 과한 건 아닌지, 우리 아이 나이에 맞는지만 정확히 알려줘. 아이 거라 실패하면 안 된다."

## 왜 가장 강한 페인인가 — 3중 페인 구조

### ① 안전: 실패 = 죄책감 (신뢰 민감도 최대)
- 자녀 둔 성인 1,947명 조사에서 **자녀 건강 고민 1위는 면역력 증진(27.9%)**, 그 해결책으로 **'건기식 섭취'가 39.4%**. 잔병치레 케어맘의 면역 영양제 추가는 매우 전형적. ([식품음료신문](https://www.thinkfood.co.kr/news/articleView.html?idxno=87683))
- **여러 제품 동시 복용 시 성분이 누적**된다: 비타민D + 칼슘제 동시 복용은 흡수 증가로 **고칼슘혈증**(식욕감퇴·구토·신장결석, 심하면 신장 영구손상)을 유발할 수 있다. ([하이닥](https://news.hidoc.co.kr/news/articleView.html?idxno=57196))
- **지용성 비타민(A·D·E)은 체내에 축적**되어 부작용을 일으킨다(비타민A 장기 과다 → 간 손상·골밀도 감소). 수용성과 달리 "남으면 배출"되지 않는다. ([한림대 한강성심병원](https://hangang.hallym.or.kr/hallymuniv_sub.asp?left_menu=left_health&screen=ptm802&Health_No=306) · [MSD 매뉴얼](https://www.msdmanuals.com/ko/home/영양-장애/비타민/비타민-d-과잉))

### ② 미해결: 단일 제품 하나만으로도 이미 과량 (부모가 직접 계산 불가)
- 약사회 실측(2022, 24개 제품): 한 어린이 구미의 **비타민D가 6~8세 권장량의 500%(25㎍ vs 5㎍)**, 한 츄어블은 비타민A 156%·비타민D 200%. ([약사공론](http://www.kpanews.co.kr/news/articleView.html?idxno=250577))
- 연령별 기준이 다르다: 비타민D는 **12개월 미만 400IU, 소아·청소년 600IU, 상한 4,000IU**. 부모가 제품마다 연령 환산을 직접 해야 한다. ([대한소아청소년과학회](https://www.pediatrics.or.kr/bbs/index.html?code=infantcare&category=B&number=8679&mode=view) · [식약처/한국영양학회 KDRIs](https://www.foodsafetykorea.go.kr/foodcode/01_03.jsp?idx=12131))
- 비교 자체가 불가능: 같은 성분도 **mg·IU·mcg·㎍ 단위가 제각각**이고 IU는 성분마다 환산식이 다르다(비타민A 100IU ≠ 비타민D 100IU). ([스완슨코리아](https://swanson.kr/home/?bmode=view&idx=17240272))
- **"건기식 기준치는 성인 기준이라 어린이 적정량 판단이 어렵다"**는 페인이 명시적으로 존재. ([모어네이처](https://morenature.co.kr/article/진실-혹은-거짓/2/85588/))

### ③ 반복성 + 광고 불신: 페인이 계속 재발하는데 믿을 정보가 없다
- 시장이 **4년간 +52.2%**로 커지고 제형(구미·젤리)이 다양해지며 선택지가 계속 늘어난다(구미는 전체 건기식의 10.5%). 환절기마다 새 제품을 추가/교체. ([디지틀조선일보](https://digitalchosun.dizzo.com/site/data/html_dir/2025/04/24/2025042480137.html))
- 그런데 정보는 못 믿는다: **78.6% 항상 리뷰 확인 vs 79.2% 자작 리뷰 의심**, 맘카페 허위후기 2.6만 건 사건. ([엠브레인 트렌드모니터](https://www.trendmonitor.co.kr/tmweb/trend/allTrend/detail.do?bIdx=1599&code=0201&trendType=CKOREA) · [서울경제](https://m.sedaily.com/amparticle/12221504))

## Jobs To Be Done
- **기능적**: "지금 먹이는 제품 목록을 넣으면, 아이 연령 기준으로 **중복·과다·적정성을 근거와 함께** 점검해줘."
- **정서적**: "광고가 아니라는 확신을 줘. 아이한테 잘못 먹이는 게 가장 무섭다."
- **사회적**: "내가 꼼꼼하게 챙기는 엄마라는 느낌을 받고 싶다."

## 한 줄 요약 (과제1 제출 문장 후보)
> **"이미 아이에게 영양제 2–3개를 먹이고 있고 환절기마다 하나씩 더 추가하는 40대 워킹맘 — 성분이 겹치는지·과한지·우리 아이 나이에 맞는지가 가장 두렵지만, 검색하면 다 광고라 믿을 근거가 없다."**
> 안전(아이 몸) × 반복(환절기마다) × 미해결(아무 앱도 중복 점검 안 함)이 겹쳐, 35–50세 여성 쇼핑 페인 중 가장 날카롭다.
