# P2. 워킹맘 — "김지현" (가상 프로필)

> 페인 강도: ★★★★☆ (상) · 역할: 주력 페르소나(P3)에 오버레이할 핵심 변수 = "시간 빈곤"

## 프로필

| 항목 | 내용 |
|---|---|
| 나이 | 42세 |
| 가족 | 초등 2학년 + 유치원생, **맞벌이** |
| 일/생활 | 풀타임 근무, 퇴근 후 육아·집안일로 가처분 시간 거의 없음 |
| 구매 채널 | 쿠팡(로켓배송) 중심, 이동 중 모바일로 결정 |

## 한 줄 정의
> "퇴근길 5분 안에, 믿을 수 있게 정해줬으면 좋겠다. 비교할 시간이 없다."

## 배경 — 왜 이 페르소나가 존재하나 (근거)

- **18세 미만 자녀 둔 유배우 가구의 58.5%가 맞벌이**, 연령별 맞벌이 비중은 **30대 61.5%·40대 59.2%**로 전 연령 최고. ([데이터뉴스](https://www.datanews.co.kr/news/article.html?no=140534) · [KOSIS/지표누리](https://www.index.go.kr/unity/potal/indicator/IndexInfo.do?clasCd=10&idxCd=F0034))
- **30대 여성 고용률 71.3%**(2024), 2015년 대비 +14.4%p. 일하는 엄마가 표준이 됨. ([매거진한경](https://magazine.hankyung.com/business/article/202506196172b))
- 건기식 **인터넷몰 구매 69.8%**, 주 구매처 **쿠팡 45.7%**. 의사결정이 짧고 모바일에서 일어난다. ([건강기능식품협회](https://www.khff.or.kr/user/info/InfoBoardUserView.do?_menuNo=369&boardSeqno=10035&postsSeqno=119022) · [오픈서베이 2025](https://blog.opensurvey.co.kr/trendreport/health-supplement-2025/))

## 핵심 페인

1. **시간 빈곤** — 약사·소아과에 물어보는 게 가장 신뢰되지만(닥터나우 등 비대면도 예약·대기 필요) 시간을 못 낸다. ([닥터나우](https://doctornow.co.kr/))
2. **검증 불가 상태에서의 구매** — 비교·확인 없이 쿠팡 후기에 의존해 사는데, 그 후기마저 못 믿는다(78.6% 확인 vs 79.2% 자작 의심). ([엠브레인 트렌드모니터](https://www.trendmonitor.co.kr/tmweb/trend/allTrend/detail.do?bIdx=1599&code=0201&trendType=CKOREA))
3. **죄책감** — 바빠서 대충 고른다는 자책 → "그래도 아이 건강은 실패하면 안 된다."

## Jobs To Be Done
- "내가 조사할 시간이 없으니, **근거까지 붙여서 빠르게** 결론을 줘. 후회 없게."

## 현재 대안과 한계
- 비대면 진료(닥터나우 800만 사용자) → 신뢰 높지만 즉시성 낮음 ([닥터나우](https://doctornow.co.kr/))
- 쿠팡/네이버 가격비교 → "싼 것"은 알려줘도 "우리 아이에게 맞는지/겹치는지"는 답 못 함 ([머니투데이](https://www.mt.co.kr/living/2025/03/13/2025031214215669745))

## 역할
독립 페르소나라기보다 **P3에 얹는 결정적 제약(속도)**. "근거 있는 결론을 빠르게"라는 우리 제품의 UX 요구사항을 정당화한다.
